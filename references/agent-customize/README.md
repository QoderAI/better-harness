# Agent Customize

## Purpose

Use this domain for configured coding-agent assets and their quality,
authority, routing, overlap, observed use, and maintenance boundaries.

## Owns

- `routing.md`: host-neutral owner and reference selection.
- Rules and agent guides: `agents-md-review.md`.
- Skills: `skill-discovery.md` and `skill-review.md`.
- MCP, Memory, Hooks, Custom Agents, and cross-asset learning:
  `mcp-review.md`, `memory-review.md`, `hooks-review.md`,
  `custom-agents-review.md`, and `knowledge-assets-review.md`.
- Inventory and authority: `global-assets.md`.
- Provider-specific notes: `platforms/claude.md`, `platforms/codex.md`,
  `platforms/qoder.md`, `platforms/qwen.md`, `platforms/copilot.md`,
  `platforms/pi.md`, and `platforms/workbuddy.md`.

## Does Not Own

- Session-derived evidence; use `../session-evidence/`.
- Static project, observability, design, acceptance, or recovery evidence; use
  `../project-harness/`.
- Repeated-work owner selection; use `../loop-engineering/`.
