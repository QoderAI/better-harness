# Session Evidence

## Purpose

Use this domain for bounded, privacy-safe evidence derived from coding-agent
sessions. It describes collection and interpretation; it does not own project
quality or configured agent assets.

## Owns

- `sessions-diagnostics.md`: source discovery, scope, selection, privacy, and
  Task Episode construction.
- `session-insights-report.md`: reader-facing session insight projection.
- `session-usage-efficiency.md`: usage, model attribution, and long-session
  evidence boundaries.

## Does Not Own

- Static project and delivery evidence; use `../project-harness/`.
- Rules, Skills, MCP, Memory, Hooks, Custom Agents, or Plugins; use
  `../agent-customize/routing.md`.
- Durable owner selection for repeated work; use `../loop-engineering/`.

## Read Next

Start with `sessions-diagnostics.md`. Add `session-insights-report.md` only for
a reader-facing insight report, and `session-usage-efficiency.md` only for
usage, cost, model, or long-session questions.
